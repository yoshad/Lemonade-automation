# 🍋 Lemonade Automation Suite

Automated end-to-end tests for [Lemonade's](https://www.lemonade.com) homepage using **WebdriverIO**, **TypeScript**, and **Cucumber**. This public repo is designed to be cloned, installed, and run by anyone with Node.js.

## 🚀 Features

- Verifies the "Check our Prices" CTA is visible
- Tests navigation to the login page via the "My Account" link
- Clicks through product links (Renters, Homeowners, Car, Pet, Life, Giveback) and verifies page redirects
- 🧪 Uses Cucumber BDD-style scenarios

---

## 🧰 Tech Stack

- [WebdriverIO](https://webdriver.io/)
- [Cucumber](https://cucumber.io/)
- [TypeScript](https://www.typescriptlang.org/)
- [Chai](https://www.chaijs.com/) for assertions
- Chrome (headful or headless)
